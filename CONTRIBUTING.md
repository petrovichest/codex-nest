# Contributing

CodexNest accepts contributions through reviewed pull requests.

1. Fork the public repository.
2. Create a branch in the fork and make the change there.
3. Open a pull request against `petrovichest/codex-nest:codex/mvp`.
4. Wait for the required CI checks and owner review before merge.

Direct write access to the upstream repository is not required for
contributors. Security-sensitive changes to workflows, installers, updates, or
Android signing must be reviewed by the repository owner.
